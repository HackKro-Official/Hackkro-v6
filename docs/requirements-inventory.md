## 1. Roles, Identity Model & Access Matrix (Chapters 03, 06, 50)

### Identity Principles
- **Single Person-Level Identity**: One `User` record per person; users can hold multiple memberships and roles across organizations and platform capabilities without creating separate accounts.
- **Account States**: `pending_verification`, `active`, `restricted`, `suspended`, `deletion_requested`, `anonymized`, `closed`. State transitions are audited; suspension never erases evidence or financial records; account closure revokes all sessions immediately.
- **RBAC + ABAC Authorization (Deny by Default)**: Every server route validates the authenticated user, active organization/workspace context, resource ownership/assignment, status constraints, and action permissions.

### Core Roles & Scopes
| Role Key | Scope | Core Permissions |
|---|---|---|
| `guest` | Public | Browse public pages, search/filter public listings, verify public credentials |
| `participant` | Person | Manage profile/resumes/portfolio/privacy, apply, form/join teams, submit deliverables, take assessments, enroll in courses, practice, book mentors, apply for jobs, manage sessions/data export |
| `team_captain` | Team | Edit team details, invite/remove members, transfer captaincy (with acceptance), lock/submit/withdraw team application |
| `mentor` | Person/Marketplace | Publish verified/self-reported mentor profile, set availability slots, host sessions, complete bookings, receive feedback |
| `organizer_owner` | Organization | Full organization control, billing/payouts, member invitations, verification submission, all event & campaign settings |
| `organizer_manager` | Organization | Create/edit/publish opportunities within granted scope, configure forms/eligibility/rounds/rubrics, check-in, contingency mode, campaigns |
| `evaluator` | Event/Assignment | Read assigned submissions only (respecting blind mode & COI declaration), enter rubric scores & evidence notes, submit/lock evaluation |
| `recruiter` | Organization | Manage assigned job requisitions, search consented candidates, manage ATS pipeline stages, schedule interviews, fill scorecards, draft offers |
| `recruiter_admin` | Organization | Manage company employer page, requisition approvals, hiring team permissions, offer compensation/HR approval, talent pool retention |
| `college_admin` | Institution | Manage verified institution profile, verified student cohorts, placement drives, bulk institutional invites, cohort analytics |
| `campus_ambassador` | Campaign | Manage ambassador profile, attributable referral codes/links, promotional tasks, campaign performance |
| `support_agent` | Platform | Search non-sensitive support reference IDs, manage support tickets with SLA, user-visible replies & internal notes (never view passwords/OTPs) |
| `moderator` | Platform | Review flagged content/listings/community reports, issue warnings, hide content, restrict/suspend with reason codes & appeals |
| `platform_admin` | Platform (MFA) | Organization verification, feature flags, certificate correction/revocation, payment/refund dual approval oversight, global operations |
| `security_admin` | Platform (MFA) | Security incidents, break-glass access logs, audit log inspection, session revocation, abuse mitigation |

## 2. Complete Module & Sub-Feature Inventory (Chapters 01–59)

### Module A: Identity, Authentication & Security Gateway (Ch 04, 05, 06, 46, 47, 59)
- Dedicated `/login`, `/signup`, `/otp`, `/forgot-password`, `/reset-password`, `/onboarding`, `/oauth/callback/[provider]`, `/settings/security`.
- **Login Identifier**: Email (case-normalized, trimmed, supports `+` aliases) or international phone (country picker + E.164 storage). Zero account enumeration (`"If an account matches these details, we'll send the next step."`).
- **Auth Methods**: Password (Argon2id/scrypt memory-hard hashing, common/breached password rejection, allow paste & password managers, show/hide toggle), Passwordless OTP / Magic Link (6-digit CSPRNG, hashed at rest, short-lived, single-use, attempt limits, resend supersedes old codes, single `autocomplete="one-time-code"` input + WebOTP), Google OAuth 2.0/OIDC adapter (state, nonce, issuer, audience, redirect URI verification, safe account linking requiring password/OTP proof if email already exists).
- **Onboarding & Multi-Role**: Minimal signup fields + age/DOB gate + country + terms/privacy consent version/locale/timestamp; initial intent selector (`student`, `recruiter`, `organizer`, `mentor`, `college`) that configures first dashboard without locking persona; workspace/role switcher for multi-role accounts; safe internal allowlisted `returnTo` URL revalidating opportunity state post-login.
- **Sessions & Protection**: HttpOnly, SameSite=Lax, Secure (prod) session cookies; CSRF double-submit/token + Fetch Metadata checks; session rotation on login/privilege change/reset; device/session management list + logout & logout-all-devices; step-up recent re-auth for sensitive actions; progressive rate limiting & throttling; device/security alert notifications.
- **API Endpoints (`/api/v1/auth/*`)**:
  `POST /identify`, `POST /login/password`, `POST /otp/request`, `POST /otp/verify`, `POST /oauth/:provider/start`, `GET /oauth/:provider/callback`, `POST /password/forgot`, `POST /password/reset`, `POST /logout`, `POST /logout-all`, `GET /sessions`, `DELETE /sessions/:sessionId`, `POST /link-identity`, `DELETE /identities/:identityId`, plus `POST /register`, `GET /me`, `POST /switch-workspace`, `POST /onboarding`.

### Module B: Public Site, Discovery & Opportunity Marketplace (Ch 07, 08, 09, 10, 11)
- **Public Navigation & Homepage**: Guest value proposition, popular categories, featured opportunities, how it works, trust signals, registration prompt; personalized authenticated homepage with recommendations (with transparent explanations like `"Matches your Python skill"` + interest tuning/dismissal), deadlines, active apps, upcoming assessments, learning progress, saved items.
- **17 Opportunity Types**: `job`, `internship`, `hackathon`, `coding_contest`, `quiz`, `case_study`, `business_simulation`, `innovation_challenge`, `scholarship`, `workshop`, `webinar`, `conference`, `college_fest`, `cultural_event`, `mentorship_program`, `course`, `community_challenge`.
- **Search & Filters**: Keyword/typo-tolerant search across title, organizer, description, category, skills, location, tags; autocomplete & recent searches; filters for category, type, skill, education level, graduation year, branch, location, work mode, paid/unpaid, prize/stipend range, deadline, experience, team size, eligibility, application status; selected filter chips, clear-all, stable sorting (`relevance`, `newest`, `deadline`, `popularity`); strict visibility enforcement (`public`, `unlisted`, `invite_only`, `org_only` — never expose private drafts/invite-only in public search).
- **10-Step Listing Creation Wizard & Lifecycle**: `draft -> pending_review -> approved -> scheduled -> live -> registration_closed -> in_progress -> completed -> results_published -> archived` (plus `cancelled` / `rejected` with reason codes). Auto-save drafts, validation summary, post-application edit impact review + confirmation + reason + participant notification, `OpportunityVersion` immutable rule snapshots.
- **Opportunity Detail Page**: Above-the-fold metadata, organizer verification badge, dynamic state-aware CTA (`Apply`, `Register`, `Join Team`, `Continue Application`, `Start Assessment`, `Submit Work`, `View Status`, `Registration Closed`, `Results Published`), tracks, rounds, judging criteria, FAQs, organizer contact, fee/refund policy, data-use notice, accessibility notes, report-listing dialog.

### Module C: Dynamic Forms, Eligibility & Registration Engine (Ch 12, 15)
- **Form Builder**: 17 field types (`text`, `long_text`, `email`, `phone`, `number`, `date`, `dropdown`, `multi_select`, `radio`, `checkbox`, `file_upload`, `url`, `education`, `work_history`, `skill`, `consent`, `conditional`), field ordering, help text, validation rules, profile auto-fill mapping, retention classification, export column name, section instructions, conditional branching.
- **Eligibility Engine**: Server-side evaluation against structured rules (`country`, `minAge`, `educationLevels`, `graduationYears`, `institutions`, `courses`, `branches`, `minExperienceYears`, `requiredSkills`, `location`, `workAuthorization`, `teamSize`); clear user-friendly mismatch explanations without leaking private thresholds; organizer manual-review exception workflow with reason & audit log; eligibility snapshot stored on `Application`.
- **Registration & Application Pipeline**: Atomic capacity reservation + idempotency key preventing duplicate submits; payment integration gate; 12 canonical statuses (`draft`, `submitted`, `under_review`, `shortlisted`, `assessment_invited`, `assessment_completed`, `interview`, `waitlisted`, `selected`, `rejected`, `withdrawn`, `cancelled`) with custom display labels, actor/timestamp/reason/note transition log, receipt & pass ID generation.

### Module D: Participant Workspace, Profile, Resume, Portfolio & Teams (Ch 13, 14, 16)
- **Participant Dashboard & Personal Task Center**: Synchronized overview cards + Personal Task Center pulling live actions from applications, assessments, submissions, payments, profile completion, and team invites; completing a task updates its authoritative source state.
- **Privacy & Portability**: Granular toggles (profile visibility, resume visibility, recruiter discovery, contact sharing, marketing consent, public portfolio fields), machine-readable JSON data export, account deletion/anonymization request workflow.
- **Profile, Resume Versioning & Skill Graph**: Education, experience, projects (role, tech stack, links, contribution statement), achievements, certifications, languages, resume upload (PDF/DOCX MIME & size check, quarantine/scan pipeline, version snapshots so historical applications never mutate, user-correctable machine-extracted metadata), skill provenance (`self_declared`, `assessed`, `endorsed`, `verified`).
- **Teams & Collaboration Workspace**: Create team, track selection, invite by username/email, accept/decline, enforce min/max team size & no conflicting teams for same opportunity, roster lock at deadline, replacement requests, captain transfer (acceptance or admin recovery), team workspace with milestones, shared files, task checklist, scoped discussion, activity log, immediate access revocation upon removal.

### Module E: Hackathons, Submissions, Assessments, Proctoring, Judging & Certificates (Ch 17–21, 34)
- **Hackathon Live Operations**: Tracks (track-specific eligibility/rubric/submission template), problem statements, schedules in event timezone, mentors, sponsors, QR & roster check-in, announcements, public/private leaderboards, incident/contingency mode (outage, deadline extension propagating across countdowns/APIs/notifications, judge unavailability, venue change).
- **Submissions & Versioning**: Text, URL, PDF, PPT/PPTX, DOC/DOCX, XLS/XLSX, image, audio, video, ZIP, repo link; real MIME/magic-byte check + checksum + quarantine/scan + signed scoped downloads; lifecycle (`not_started`, `draft`, `submitted`, `late_submitted`, `under_validation`, `accepted`, `rejected_for_format`, `resubmission_requested`, `final_locked`); multi-version history showing exact evaluated version; contribution statements; transparent similarity indicators & participant appeal route.
- **Assessment Engine**: Question bank with difficulty, topic, skill mapping, points, explanation visibility, version, accessibility metadata; formats (`mcq_single`, `mcq_multi`, `true_false`, `numerical`, `short_text`, `essay`, `coding`, `sql`, `debugging`, `file_upload`, `audio_video`, `typing`, `communication`, `psychometric`, `case_study`, `scenario_simulation`); fixed & randomized pools, negative marking, partial credit, sectional & overall timers, autosave/resume, calculator policy, accommodations (extra time, screen reader, keyboard); isolated sandboxed code execution adapter with test cases & hidden tests; separate raw/normalized/rubric/override scores.
- **Proctoring & Fairness**: Consent notice, purpose & retention; full-screen/tab-switch/browser/webcam/copy-paste/anomaly telemetry; risk bands (`low`, `medium`, `high`) with reason codes — NEVER auto-reject without human review; documented appeal path & SLA.
- **Judging & Rubrics**: Weighted rubric builder (validated sum=100 or normalized), track/round rubrics, freeze upon evaluation start; reviewer assignment by track/skill/capacity + COI declaration + self-review prevention + blind mode; calibration samples & progress dashboard; draft/submit/lock evaluation; outlier detection & second-review/tie-break workflow.
- **Certificates & Badges**: Templates (participant, event/course, issuer, achievement, date, unpredictable credential ID, QR code, verification URL, signature/brand), duplicate prevention, corrected/revoked states; public `/verify/[credentialId]` rate-limited verification page exposing only intended credential metadata; shareable profile badges (`attendance`, `completion`, `finalist`, `winner`, `assessed_skill`).

### Module F: Learning, Practice & Mentorship (Ch 22, 23, 24)
- **Learning & Cohorts**: Course catalog (outcomes, syllabus, level, duration, instructor, prerequisites, language, mode, price/free, cert rules, accessibility), lessons (video with captions/transcripts, text, downloadable resources, quizzes, assignments, discussions), explicit completion criteria (not just video play), Cohorts (enrollment windows, schedule, attendance, announcements), Learning Paths with pause/resume.
- **Practice & Mock Interviews**: Categorized by company, role, skill, topic, difficulty (`aptitude`, `reasoning`, `verbal`, `domain`, `coding`, `sql`, `system_design`, `case`, `communication`); post-submission explanations; attempt history & analytics (accuracy, speed, topic strengths, export/delete personal history); Mock Interview flow (configure role/exp/type, book or run AI-labeled simulation, review transcript/action items).
- **Mentorship Marketplace**: Mentor profiles distinguishing platform-verified vs self-reported attributes, session types, pricing, cancellation policy, availability slots; atomic slot reservation preventing double-booking; booking lifecycle (`booked -> confirmed -> completed -> feedback -> settlement`, plus `cancelled`, `rescheduled`, `no_show`, `refunded`, `disputed`); private meeting links, block/report tools, verified booking reviews.

### Module G: Jobs, Recruiter ATS, Sourcing, Interviews & Offers (Ch 25, 26, 27, 28)
- **Jobs, Internships & Employer Pages**: Full Job schema (disclosed salary vs `"not shared"` — never fabricated), profile+resume snapshot apply, screening questions, explicit recruiter access consent, external-apply warning; Company brand pages with verified domain, culture, teams, locations, benefits, active jobs/events, follow button.
- **Recruiter ATS & Pipeline**: Versioned Requisition workflow (`create -> hiring_team -> stages -> screening -> publish -> assess -> interview -> decision -> offer -> close`), 15 canonical pipeline stages (`new`, `profile_review`, `screening`, `assessment_invited`, `assessment_completed`, `interview_1`, `interview_2`, `final_review`, `offer_approval`, `offer_sent`, `offer_accepted`, `offer_declined`, `rejected`, `withdrawn`, `hired`) + custom stage labels; private internal notes strictly separated from candidate exports/emails; configurable automation rules & human-reviewed AI summaries logged with model/prompt/override reason.
- **Talent Sourcing & Outreach**: Consent-aware candidate search (respects `recruiterDiscovery` opt-in; hides contact details until opt-in/application), saved searches, talent pools with reason/owner/retention expiry, approved outreach templates with opt-out & rate limits + delivery telemetry.
- **Interviews, Scorecards & Offers**: Availability + timezone-labeled scheduling + conflict detection + panel composition + calendar/meeting adapter; structured competency scorecards required before debrief; Offer workflow (`draft -> compensation_approval -> hr_legal_approval -> sent -> viewed -> accepted/declined/expired/withdrawn`), explicit auditable candidate acceptance, e-signature confirmation flag.

### Module H: Institutions, Campus Ambassadors, Community & Microsites (Ch 29, 30, 31)
- **College & Institution Workspace**: Verified institution profile (distinct from user claims), departments, placement cell contacts, verified student cohorts, placement drives (eligibility, windows, company sessions, assessments, interview slots, attendance, offer tracking, cohort reports), bulk institutional invites.
- **Campus Ambassador, Referrals & Community**: Application -> selection -> onboarding -> campaigns -> attributable referral codes with expiry/campaign rules & lifecycle (`clicked -> registered -> verified -> qualified -> rewarded`) + self-referral/duplicate-account fraud detection; Community groups, followed organization announcements, moderated posts, report queue, block/mute & moderator audit logs.
- **Microsites & Branding**: Controlled no-code section builder (`hero`, `overview`, `schedule`, `tracks`, `speakers`, `judges`, `sponsors`, `faqs`, `prizes`, `eligibility`, `cta`, `venue`, `contact`, `footer`), responsive theme tokens, draft/publish & versioned snapshots, SEO metadata, Open Graph, robots/noindex for private events, strict XSS/script stripping.

### Module I: Notifications, Payments, Admin, Moderation, Analytics, Compliance (Ch 32, 33, 35–59)
- **Notifications & Campaigns**: In-app inbox, email/SMS/push adapters, localized templates, separate transactional/security/marketing preferences, deduplication keys, quiet hours, organizer bulk campaigns with audience preview, test send, large-campaign approval & unsubscribe handling.
- **Payments, Ticketing & Ledger**: Ticket tiers, coupons, team pricing, sales windows, taxes/fees transparency, atomic inventory reservation; Order -> PaymentIntent -> Server Webhook signature verification -> Paid -> Receipt -> Reconciliation; append-only `LedgerEntry`; full/partial refunds with dual approval for high-value transactions, disputes/chargebacks.
- **Admin Console, Moderation & Support**: User search & state management, organization verification, listing moderation, flagged content workflow (`flagged -> triaged -> assigned -> under_review -> action_taken/no_violation -> appeal_pending -> resolved`), support tickets with SLA & non-sensitive Support Reference IDs (`HK-SUP-...`), feature flags with rollback kill switches, audit log viewer, incident dashboard.
- **Platform Cross-Cutting**: OpenAPI `/api/v1/openapi.json`, signed webhooks with replay & delivery logs, idempotent background jobs queue with retries/dead-letter, file upload quarantine/scan/signed URLs, analytics event taxonomy (`page_view` through `payment_completed`) & KPI engine, asynchronous PII-masked exports, i18n dictionary (`en`, `hi`), WCAG 2.2 AA accessibility.
